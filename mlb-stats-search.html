Diamond Query

Ask anything about MLB stats.

Type a question in plain English. It parses your query, pulls real game logs from MLB's official Stats API, and counts the games that match — showing every one.

Data: MLB Stats API (unofficial, public). Regular-season games only.
This is an MVP. The English-to-query step here is a rule-based parser that handles common patterns — the production version would hand this to an LLM for true "ask anything" flexibility. See the header comment in the source.
